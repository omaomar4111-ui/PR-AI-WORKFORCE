## 1. الملخص التنفيذي (Executive Summary)

منصة **PR-AI-WORKFORCE** هي نظام متكامل لإدارة القوى العاملة المدعومة بالذكاء الاصطناعي. تم بناء النظام من الصفر ليكون سريعاً، آمناً، وقابلاً للتوسع. يعتمد النظام على وكلاء ذكاء اصطناعي (AI Agents) متخصصين في 8 أقسام تشغيلية لأتمتة المهام وتوليد المخرجات، مما يوفر وقتاً هائلاً في العمليات التشغيلية، مع الحفاظ على الرقابة البشرية (Human-in-the-Loop) عبر نظام موافقات مركزي.

---

## 2. البنية التحتية والتقنيات (Tech Stack)

*   **الواجهة الأمامية (Frontend):** 
    - Next.js 14 (App Router) مع React Server Components و Tailwind CSS.
    - تطبيق ويب تقدمي (PWA) قابل للتثبيت ومزود بـ Offline Fallback.
    - إدارة الحالة والأداء الفوري عبر Optimistic UI و `@tanstack/react-virtual`.
*   **الواجهة الخلفية (Backend):** 
    - FastAPI (Python 3.11) في حاوية Docker متعددة المراحل (Multi-stage).
    - تتبع موزع ومراقبة أداء عبر OpenTelemetry (W3C Trace Context).
    - بث مباشر للردود عبر Server-Sent Events (SSE).
*   **قاعدة البيانات (Database):** 
    - Supabase (PostgreSQL 17) مع دعم `pgvector` للبحث الدلالي وحفظ الذاكرة طويلة المدى.
    - مجمع اتصالات PgBouncer (Transaction Mode) عبر المنفذ 6543.
*   **طبقة الكاش (Caching):** 
    - Upstash Redis مشفرة بـ TLS عبر بروتوكول `rediss://`.
    - تطبيق نمط Cache-Aside مع إبطال موجه للكاش فور أي عملية تعديل (Mutation).
*   **الاستضافة (Hosting):** 
    - **Vercel:** استضافة الواجهة الأمامية على شبكة الـ Edge العالمية.
    - **Railway:** استضافة الباك إند وخدمات FastAPI و Docker.

## 4. الأمان وحماية البيانات (Security & Compliance)

*   **أمان قاعدة البيانات وعزل البيانات:** 
    - تفعيل Row-Level Security (RLS) على جميع الجداول الـ 21 لضمان العزل الصارم بين بيانات المؤسسات والعملاء.
*   **التحكم في الوصول والصلاحيات (RBAC):** 
    - فصل دقيق بين صلاحيات المالك (Owner) وصلاحيات أعضاء الفريق (Member) والعملاء.
*   **أمان الكود وجودة البرمجيات:** 
    - تفعيل Pre-commit hooks إجبارية (Ruff, ESLint, Prettier) لفحص الكود وتنسيقه آلياً قبل كل commit.
    - تكامل إطار Everything Claude Code (ECC) وأدوات pyscn و Judges لضمان جودة الكود.
*   **إدارة الأسرار:** 
    - استبعاد تام لكافة المفاتيح وكلمات المرور من مستودع Git (`.gitignore` محكم).
    - إدارة الأسرار عبر لوحات تحكم Vercel و Railway المشفرة.
*   **حماية الاتصال وسياسة CORS:** 
    - تكوين صارم ومحكم لـ `CORSMiddleware` يسمح فقط للواجهة الأمامية المعتمدة بالتواصل مع الباك إند مع حماية الترويسات (Security Headers: CSP, HSTS, X-Frame-Options).
